# fun-backend — Learning Notes Repo

Personal learning notes and experiments across Java, GenAI, networking, and more.

## Structure

```
Java/           Java concepts — basics, threads, regex, POJO/Enum/Singleton
CN/             Computer networking — SSL/TLS, SSH
genAI/          LangChain, LangGraph theory and code examples
API_Basic/      REST/API fundamentals
odata/          OData protocol notes
architecture/   System design and architecture notes
Claude_Code/    Claude Code experiments (e.g. expense-tracker)
DeepLearning/   Deep learning notes
```

## Conventions

- Each topic lives in its own folder with a `notes.md` for theory
- Code samples sit alongside notes in the same folder
- Folder names use `PascalCase` or `snake_case` matching existing siblings

## What Claude should know

- This is a **personal learning repo** — no production code, no deployments
- Notes are written incrementally; incomplete sections are normal
- Direct pushes to `master` are allowed here (personal repo, no PR needed)
