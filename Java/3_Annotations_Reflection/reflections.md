- What are the disadvantages of Reflection in Java?
  - Performance: Reflection is slower than normal method/field access because operations are resolved at runtime.
  - Breaks Encapsulation: Reflection can bypass private access and modify internal data.
  - Type Safety: Errors may only be discovered at runtime instead of compile time.
  - Security Risk: Reflection can access restricted members if access checks are bypassed.
  - Complexity: Reflection makes code harder to read, understand, and maintain.
  - Breaks Design Guarantees: It can bypass restrictions such as a Singleton's private constructor.
